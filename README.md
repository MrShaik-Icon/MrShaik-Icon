- **ServiceNow Development & Implementation:** ITSM (Incident, Change, Problem, Request), Catalog Items, Order Guides, SRM enhancements, Business Rules, Client Scripts, UI Policies, UI Actions, Script Includes, ACLs, Flow Designer (subflows and actions), native workflows, SLAs, Events, Notifications, Transform Maps, Case Management and custom applications.

- **What I bring:** strong communication, requirement gathering, gap analysis and solution design with clients and end users, full ownership of tasks with minimal escalation, and a quick-learning mindset under tight timelines.
